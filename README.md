# layered-motion-video

固定原创卡通演员、单一旁白、分层插画和关键帧动画的泛知识视频生成 Skill。

目标是将中文口播文案转化为具有稳定角色形象、可复用场景、简单人物动作、动态图解与适度荒诞讽刺风格的知识解说视频。主要覆盖生活经济、消费心理、认知成长、职场现象、社会规律与趣味生活科学。

## 核心制作机制

```text
中文口播文案
  → 按知识故事和旁白语义拆分主画面
  → 调用固定原创演员与场景素材库
  → 按需生成独立人物姿势、背景、道具
  → 审核分层静态构图
  → 配音与语音对齐
  → 生成角色/道具/气泡/文字/图解的动作时间轴
  → Remotion 动画预览和用户审核
  → 视频、旁白和字幕合成
```

首版默认：16:9、1920×1080、30 帧/秒，旁白驱动，人物以姿势切换和对象运动为主。采用 Python 管理工作流、JSON Schema 约束动画输入、Remotion 执行动画、FFmpeg 完成音视频处理。

## 首个候选角色世界

《怪理镇》作为首批验证素材包候选：阿团（水豚）、狐九（狐狸）、乌点（乌鸦）、阿砾（河狸），辅助角色叮盒。角色形象在不同知识主题中稳定复用，职业与叙事身份根据每期内容变化。

人物名称、物种、色彩和标准设定图在完成用户美术审核后正式锁定为资产版本。

## 基准样片

《阿团去超市买28元的东西，最后为什么花了166元？》

使用七个主画面验证人物一致性、透明贴图合成、姿势替换、商品路径动画、动态气泡、数字对比、音画同步和增量重渲染。

## 项目阶段

当前仓库处于**方案与工程规划阶段**。`DESIGN.md` 和 `docs/IMPLEMENTATION_PLAN.md` 是后续实现、测试和审核的设计基线。P0 将建立正式的 Skill 入口、协议 Schema 与项目 CLI；之后依次完成素材体系、动画组件、语音与审核、Agent 自动编排及基准样片。
