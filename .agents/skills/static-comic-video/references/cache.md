# SC-P6 阶段缓存与失败恢复

沿用 `compile / align / preview / render-visual / mux / verify`，不增加自动批准命令。单期串行运行；缓存单位是阶段产物和整条视觉轨，没有镜头分段缓存。缓存位于单期 `work/cache/<stage>/<key>/`，不进入 Remotion public。

缓存检查、修复和重跑由 Agent 执行，不向用户索要命令行操作。许可若存在，仅作为原始元数据的一部分参与完整性与缓存失效判断；没有许可证据或商业授权不阻塞本地制作，不让用户补证明来恢复缓存。

| 阶段 | 内容与版本键 | 命中仍检查什么 |
|---|---|---|
| audio | 源音频实际 SHA256、FFmpeg 字节、适配器代码、48k/16k 配置 | 两份 PCM 和音频记录的缓存字节，发布副本摘要 |
| image-authorization | 当前渠道策略、资产/来源/可选许可备注、审图收据、供图计划/候选摘要、协议/编译版本 | 来源记录、候选、实际图片、已有附件完整性、内容确认每次实时检查；不审核商业许可，命中仅复用检查记录 |
| image-shot-* | 每张原图 SHA256、cover/主体框/运镜/物理时钟、背景、处理器与 Pillow 版本 | 预处理 PNG、cover、逐帧几何报告的实际字节 |
| coarse-asr / alignment | PCM、服务地址/模型锁、读法/窗口/人工覆盖计划、适配器和运行包版本 | 模型锁字节每次验证；语音派生结论重放检查；失败的后端一致性或畸形 worker 结果不缓存 |
| timeline / staging | 已重新通过门禁的分镜、编译/协议版本；所有锁定输出字节 | 暂存路径和 content-addressed 原图完整性；损坏 public 明确阻止，不静默掩盖 |
| remotion-build | 渲染源码/配置/锁文件、已安装版本、Node、入口、public 图片摘要 | 构建目录完整文件清单与 SHA256 |
| visual-preview / visual-final | 构建内容、执行 props、浏览器/Node、输出规格、验证器版本 | 缓存文件摘要、全片解码、帧数/尺寸/流/时钟；已发布视觉轨缺失或损坏会强制重渲染 |
| mux-preview / mux-final | 视觉轨与母带实际字节、FFmpeg、输出规格、验证器版本 | 全片视频帧摘要一致、AAC 全文逐秒内容及头尾完整性 |

每次访问写入 `reports/cache/<stage>.json`，包括 `key`、`HIT / REBUILT / FAILED` 和原因。该文件是各阶段最新记录，不是无限追加日志。内容变化保留不同键的旧缓存；没有自动清理策略。清单缺失、字段损坏、错误 key、产物丢失/多余或字节损坏均不能命中。缓存只用于本地一致性检查，不是对不可信写入者的认证系统。

`validate` 不写缓存；只读取已验证的逐图缓存，缺失时内存重算。授权检查仍会检查供图候选的几何条件。`compile` 复用逐图结果并写入当前时间线和暂存；任何供图/许可/批准变化都必须先通过原有门禁。

视觉键不含配音、许可或转场解释；它们仍在当前预览/审批绑定中。仅说明改变而执行 props 相同时，可重用视觉字节，但必须重新确认语义、更新预览批准。仅配音改变时，先重新对齐并核对时间线；相同执行 props 可重用视觉轨，但母带、封装和完整试听均需更新。T、边界、运镜或转场执行变化使整片视觉重新生成。540p 与 1080p 分开缓存。

缓存 builder 只写临时目录，验证完成后才发布文件与最后的清单。音频、编译暂存、对齐结果、预览和正式媒体先准备全部文件；每个文件使用同目录临时文件与 `os.replace`，可捕获的发布异常回滚本批文件。渲染/封装失败不会覆盖旧有效预览或成片，不会改写人工批准。后端变化的原始诊断仍保存在 alignment/evidence，重试会重新请求 VoiceStudio。

`reports[/technical]/attempt.json` 保存最近交付尝试的 RUNNING / SUCCEEDED / FAILED、错误及旧记录输入摘要、文件摘要和文件验证结果。`status` 对失败尝试返回 FAILED，对尚未结束的尝试返回 INTERRUPTED_OR_RUNNING，`current_success=false`；不得把保留的旧成片当作本次成功。修复输入后重跑原命令即可，仍需当前审批。

这是单进程串行发布，不提供跨文件系统事务、并发作业互斥或断电恢复保证。强杀进程可能留下未发布临时文件或混合代次；清单/报告摘要检查会拒绝不一致代次，重跑生成当前完整结果。已验证的新文件才可能被替换到公开位置。不要同时对同一期执行多个写命令。

复跑技术探针（输出目录必须新建或为空）：

```powershell
.venv/Scripts/python.exe -X utf8 scripts/verify_cache_probe.py --output <new-probe-directory>
```

探针使用 11.981 秒合成音频和几何图片，测试批准明确标记 SYNTHETIC。真实 Remotion/FFmpeg 验证冷运行、完全相同输入命中、封装部分写入失败后旧成片/批准不变、重试恢复、删除视觉轨后的重渲染。它不调用模型、不下载素材，也不代替 SC-P7 真实样片与人工观看试听。

图片审图晋级及各阶段 JSON 写入同样复用 publish。覆盖前完成整批预检与暂存校验，审批指针最后发布。普通异常回滚；若回滚也遇到 I/O 错误，报告未恢复目标并保留原 .bak，不删除唯一原字节。先按备份恢复，再重新验证/审图；不得把磁盘混合代次视为成功。
