# 封面工坊 Fabric.js 编辑器

这是基于 Fabric.js 7.4 的浏览器实时封面编辑器，采用场景模型 v2。编辑、实时预览与高清 PNG 导出都在浏览器完成；本机 Flask 负责字体、图片素材、设计存储与版本校验。

- 正式可视化编辑器：http://127.0.0.1:8765/
- 经典 Pillow 编辑器：http://127.0.0.1:8765/legacy

两个入口共用本机字体库。浏览器版设计保存在 cover-studio/data/designs/，经典版模板仍保存在 data/preset.json。

## Windows 启动

首次使用请在本机安装 Node.js，再进入 `cover-studio` 启动。Python 会自动检查、安装和构建所需的前端资源；再次启动仅在资源发生变化时重新构建：

~~~powershell
cd D:\wx_lifeilin\github.com\lifei6671\layered-motion-video\cover-studio
.\start.bat
~~~

也可直接运行 `.\.venv\Scripts\python.exe app.py`。手动构建时，进入 `fabric-poc/` 执行 `npm ci --ignore-scripts`、`npm run build`。生成的 `node_modules/` 与 `static/fabric-poc.bundle.js` 是本地构建产物。缺少 Node.js 时经典编辑器仍能从 `/legacy` 使用。

## 双编辑界面与入口

浏览器访问 `/` 进入 Fabric.js 正式编辑器。标题、图片与图层的交互和 PNG 导出统一由浏览器完成。点击页眉「经典版编辑器」可以切换到 `/legacy`，经典版页眉也可返回正式首页。原 `/fabric-poc` 链接会跳转到 `/`。

两套界面共用字体目录，独立保存设计与默认模板：新设计位于 `data/designs/`，经典默认模板位于 `data/preset.json`。从经典模板导入时创建独立设计草稿，不会修改原文件。

## 使用流程

1. 打开正式首页 `/`，默认载入经典封面作为场景 v2 草稿。
2. 编辑标题、账号、字体、背景与头像。文字和图层变化由 Fabric.js 在浏览器直接刷新。
3. 六种画幅分别计算自动布局；切换比例会恢复该比例的手动位置。小标题与分隔线组成一个组合图层。
4. 点击「保存设计」新建或更新设计，「另存新设计」复制出独立版本。使用「本机设计库」重新打开。
5. 背景和头像经网页选择后仅入库一次；后续编辑和导出都复用浏览器图像。
6. 「导出浏览器高清 PNG」以所选画幅的实际分辨率生成图片。
7. 「查看 Python 旧版对照」可按需查看历史版式，作为人工视觉回归工具。

设计文件位于 data/designs/<id>.json，素材位于 data/designs/assets/，图片采用内容指纹命名。两个窗口同时编辑同一设计时，使用旧版本保存会得到冲突提示。

## 场景模型

Python：scene_models.py、scene_store.py、canvas_config.py。

浏览器：fabric-poc/src/scene-model.mjs、fabric-poc/src/ratio-layout.mjs。

场景包含 schemaVersion、id、revision、name、content、fontRefs、assets、backgroundStyle、layers、variants 和 activeRatio。

- 自动位置：mode=auto，坐标为空，文字变更或切换画幅时重新排版。
- 手动位置：mode=manual，坐标为画幅百分比值；横纵轴可分别保留自动定位。
- 画幅变体：variants 独立记录 3:4、9:16、16:9、4:3、4:5 与 1:1 的图层位置。
- 素材引用：legacy 用于经典模板导入，首次保存新设计时快照为 managed 内容指纹资源。
- 基础图层：背景、头像、大标题、小标题组合、账号；下一阶段按场景版本扩展自由图层。

## 专业图层与智能吸附

编辑器包含按前后顺序排列的五个基础图层：背景、圆形头像、大标题、小标题及分隔线组合、账号。图层面板支持：

- **选中与锁定**：大标题、小标题和账号可分别锁定，锁定后不能再通过鼠标拖动或缩放；头像位置当前仍由画幅布局控制，背景固定为最底层。
- **显隐**：任意基础图层可以显示或隐藏，导出的 PNG 与画布采用相同显隐状态；隐藏图层不再参与图层碰撞提示。
- **图层顺序**：可将头像、标题、字幕组合或账号逐层上移/下移，背景层始终固定为最低层。
- **吸附参考线**：打开「启用智能吸附与临时参考线」，拖动图层时可吸附画布水平/垂直中心、安全边距、其他可见图层的边缘与中心；画布中心优先，吸附阈值按照当前页面缩放比例换算。
- **导出关系**：辅助线作为独立的编辑层覆盖在画布上，不进入高清 PNG。

上述操作均记录为场景 v2 的 `layers[].visible`、`layers[].locked` 与 `layers[].zIndex`，保存设计后可以恢复。隐藏、锁定和调整顺序都支持撤销与重做；一次鼠标拖动只生成一个完成态历史记录。旧场景未包含 `visible` 字段时默认为显示。

## 图层样式与图像属性

左侧「图层属性」面板先选择编辑对象，也可以在画布或图层列表中选中对应文字图层。下方配置随对象类型切换：

- **大标题、小标题与账号**：字体大小（自动或固定）、字间距、行高倍数、文字颜色与不透明度、描边颜色与宽度、旋转角度，以及带颜色、透明度、模糊和双向偏移的文字阴影。
- **圆形头像**：不透明度、旋转角度和大小倍数；裁切为圆形的行为保持一致，基础位置仍由所选画幅计算。
- **背景**：压暗强度、垂直裁切重心和顶部柔光开关。
- **恢复默认样式**：只重置当前对象样式，不清除标题内容、字体选择、素材与手动位置。
- **修改反馈**：样式由 Fabric.js 在浏览器重新渲染。字体或字号变更会重新计算中文换行，旋转时按照变形后的包围盒保持文字位于画布内。

字号的「自动适配」优先保留书法大字、必要时分两行；切换为「固定字号」后采用用户设定的原图像素值，长标题无法完整排入画幅时会明确提示调整字号。字体样式是**设计全局图层属性**，不同画幅仍各自保留图层坐标；后续若需要各画幅分别保存字号、描边与旋转，可以扩展 `variants` 作为覆盖层。

文字样式保存在 `layers[].style`，头像样式同样保存于对应图层；背景配置沿用 `backgroundStyle`。服务端对颜色、数值范围和阴影对象做严格校验，旧模板自动补齐默认样式。编辑结果可以保存到设计库、重新打开，并通过撤销与重做恢复。

## 自由图层与组合编辑

编辑器左侧「图层与对齐」新增自由图层工具栏，可为当前设计增加文字、矩形、椭圆和图片；新增图层会显示在基础图层上方，支持拖动、调整尺寸、旋转、显隐、锁定与层级排序。自由图片先经过本机受控素材接口上传一次，保存为内容指纹文件，再由浏览器画布读取和导出。

- **自由文字**：选择字体、输入内容、调整字号、颜色与透明度，字形仍在浏览器本地渲染。
- **自由图形**：支持矩形、椭圆，填充颜色、透明度及画布变形。
- **自由图片**：支持 PNG、JPEG 与 WebP，从本机素材库读取；图片尺寸及位置保存在设计文件中。
- **组合**：在自由图层前勾选至少两个复选框，点击「组合已勾选图层」即可形成 Fabric.Group；组合后可整体拖动，改变位置后将位移同步到各成员的画布坐标。点击「解组」即可恢复成员单独编辑。
- **操作历史与保存**：添加、删除、组合/解组、整体拖动和图层属性调整均进入撤销重做；保存后可重新打开，PNG 与保存前保持一致。
- **数据组织**：为继续兼容现有场景 v2 和固定五图层，新增可选 `extras` 集合，包含 `extras.layers[]` 与 `extras.groups[]`。每个自由图层使用稳定 ID、受限的图片素材引用与画幅百分比坐标。单设计最多支持 40 个自由图层、12 个组合，每组最多 20 个成员。

当前组合以**整体位置变更**为主要操作；组合内独立调整字号、形状或局部旋转需要先解组。自由图层的位置与尺寸采用相对于画布的百分比坐标，支持每种画幅分别调整。

## 自由图层的多画幅布局

同一份设计可以同时保存横版、竖版和正方形封面。自由文字、图片、矩形与椭圆都具有一份**共享布局**和可选的**单画幅布局**；组合拖动会将当前画幅的位移同步到所有成员，但不会修改其他画幅。

在画布或图层列表选中自由图层后，左侧会显示「当前画幅布局」面板：

1. 使用「画幅比例」切换到需要编辑的比例，例如 **3:4**；通过鼠标拖动、缩放、旋转，或者输入横向位置、纵向位置、宽度、高度和角度，当前比例会自动进入独立布局状态。
2. 切换到 **16:9** 并修改图层，16:9 会保存自己的位置、尺寸和旋转；切回 3:4 时，上一步布局原样恢复。
3. 若某个比例还未设置独立布局，它会继续使用原来共享的百分比布局。
4. 点击「恢复共享布局」，仅恢复当前比例的默认几何值；点击「本画幅布局应用到全部比例」会将当前布局设为全设计共享值，并统一其他比例。
5. 保存设计后重新打开，画幅覆盖状态和各比例导出的 PNG 会保持一致；重置、应用到全部及鼠标调整均可以撤销与重做。

存储结构采用场景 v2 的 `extras.layers[].frame`（共享几何）以及 `extras.layers[].ratioFrames["16:9"]` 等可选字段（比例专用几何）。已有设计缺少 `ratioFrames` 时自动继承共享布局，字体、素材、锁定状态、图层顺序与组合关系继续复用原有数据。

**文字尺寸约束：** 自由文字的宽度与纵向缩放可以在每个画幅下分别保存，纵向缩放记录在 `ratioFrames[ratio].scaleY`。字体文件、基础字号和颜色仍属于全设计共享样式；不同画幅下的精细字号策略可以在后续版式样式覆盖阶段扩展。

## 安全区与布局质量预检

左侧「安全区与布局诊断」提供多比例参考区域与实际图层位置检查：

- **通用封面安全区**：继承当前画幅的内容边距。
- **竖屏视频界面参考**：对 3:4、9:16、4:5 画幅提供更宽的右侧与底部留白，并用浅橙色表示右侧操作区参考范围。
- **图文封面参考**：对 3:4、9:16、4:5、1:1 提供适合图文封面留白的参考范围。
- **横屏视频播放参考**：用于 16:9、4:3，强调字幕与播放器底部的参考安全区域。

所有预设都是**非官方的视觉设计参考**，不是抖音、视频号、小红书等平台公布的固定界面尺寸。平台安全范围随设备、版本、观看方式变化。可勾选「显示画布安全区」展示参考虚线和浅色遮挡区；这部分独立于 Fabric.js 导出画布，不会进入 PNG。

实时检查依据浏览器中实际图层的可见区域，区分：

| 检查 | 等级 | 说明 |
|---|---|---|
| 图层超出画布 | 错误 | 需要把内容移动回画布 |
| 安全留白不足 | 提示 | 重要文字、头像接近参考边界 |
| 参考界面遮挡 | 提示 | 与所选参考平台的操作区相交 |
| 文字与文字或图片遮挡 | 提示 | 仅报告达到一定面积的明显重叠 |
| 字号或透明度过低 | 提示 | 启发式可读性提醒 |
| 与背景颜色对比度较低 | 提示 | 基于背景色采样的近似值，不是字形笔画级精确结论 |
| 字体缺少所需字符 | 错误 | 运行「完整预检」时读取字体字符映射表，返回缺字清单 |
| 无法验证字库 | 提示 | 明确标记字体覆盖检查未完成 |

**人工确认重叠：** 诊断列表中的「确认此处允许重叠」只对当前画幅有效，保存在场景 \`quality.allowedByRatio\` 中。已经确认的关系可以在「已确认的重叠关系」列表中撤销。历史设计中的全画幅确认关系继续兼容，支持查看和撤销。删除图层、解组后会清理失效引用，撤销操作可恢复确认记录。

**导出检查：** 普通文字编辑与拖动继续由 Fabric.js 实时绘制；按下「完整预检」或「导出浏览器高清 PNG」时，才向本机字体检查接口请求字库字符覆盖。字体缺字及图层越界属于硬错误，会阻止网页下载 PNG；一般安全区与重叠提示仍允许导出。点击「导出诊断报告」生成 JSON，包含当前画幅、参考方案、问题代码、关联图层和字形检查结果。

质量配置在场景 v2 的 \`quality.profilesByRatio\`、\`quality.allowedByRatio\` 中保存；诊断结果通过实时计算生成，避免把可能过时的布局报告误当作设计固定数据。默认模板与没有质量配置的旧场景会自动得到空配置。
